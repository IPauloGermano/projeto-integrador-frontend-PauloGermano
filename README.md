# ⚡ VOLT — Tênis para ir além

Landing page desenvolvida para a **VOLT**, uma marca fictícia de tênis esportivos de alta performance com foco em estética minimalista, moderna e tecnológica.

---

## 🎯 Sobre o Projeto

O objetivo do projeto é construir uma interface visualmente limpa, rápida e responsiva utilizando as melhores práticas de desenvolvimento web frontend com tecnologias nativas.

### ✨ Destaques
- **Design Minimalista & Responsivo:** Adaptado para celulares, tablets e desktops.
- **Micro-interações:** Efeitos sutis de hover nos cards dos produtos.
- **CSS Moderno:** Uso de CSS Variables, Flexbox, CSS Grid e `aspect-ratio`.
- **Semântica & Acessibilidade:** Estrutura HTML5 limpa e organizada.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica
- **CSS3:** Estilização com variáveis, Flexbox, Grid e Media Queries
- **Google Fonts:** Tipografia com a fonte *Inter*
